# 新闻标题点击率比较：任务说明（中文对照）

> 非官方中文译文，翻译日期：2026-11-15。对应[英文原文](README.md)；有歧义时以原文及老师澄清为准。文件名和字段标识保留原样。

使用你们的 SuperAgent 预测一对新闻标题中，哪一个在 A/B 测试中具有更高的观测点击率。点击率等于点击次数除以展示次数。

每个 CSV 包含三列。使用 `headline_A` 和 `headline_B` 作为输入。目标列 `label_pairwise` 中，`1` 表示 A 的点击率更高，`0` 表示 B 的点击率更高。

使用 `train.csv`（8301 对）和 `val.csv`（940 对）进行模型开发与验证。带标签的 `test.csv`（3232 对）只能用于最终评估，并报告**测试集准确率（test accuracy）**。
