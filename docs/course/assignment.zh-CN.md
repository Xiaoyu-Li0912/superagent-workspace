# AIAA3102 期末项目：通用算法 SuperAgent

> 中文对照译文，供小组阅读，非教师发布的官方中文版。翻译日期：2026-11-15。对应[英文正式要求](AIAA3102%20-%20Final%20Project%20-%20Full%20Assignment%20Requirements.md)。保留原文结构；若有歧义，以英文原文及老师后续澄清为准。

## 1. 项目概览

本期末项目要求每组 **2–4 名学生**设计并实现一个**通用算法 SuperAgent（General Algorithm SuperAgent）**。

给定一个此前未见的任务、相应数据以及指定目标（本项目中为分类），Agent 应自主完成整个算法开发过程，包括分析任务与数据、设计方案、运行实验、根据实验结果改进方法，并最终生成一个可运行的分类模型。

最终报告中的结果必须来自 SuperAgent **完整、自主的运行**。在这些运行期间，学生不得手动修改代码、决定下一步尝试什么，或选择最终模型。

课程将提供 API key 和使用额度，供本项目调用香港科技大学（广州）API 平台上的现有大语言模型；也可以使用其他 API 提供商。

## 2. 任务

各组先有一段时间开发 SuperAgent。初期开发结束后，课程将发布若干分类任务，用于进一步测试和改进。

任务涉及表格、文本或图像数据上的二分类或多分类。各任务的数据格式、评估数据划分和指标将随任务公布。

所有任务必须由**同一个 SuperAgent** 处理。Agent 可以根据任务、数据和实验结果选择合适方法，但不得利用任务名称、数据集名称或其他任务身份信息，调用人工预先准备的任务专用方案。

本课程两个班级（L01 和 L02）均完成最终展示后，课程将提供一个此前未发布的分类任务，即**未见任务（Unseen Task）**，用于评估已提交 SuperAgent 在新任务上的表现。

## 3. SuperAgent 设计

各组可以自由设计 SuperAgent 的实现。

执行过程中，Agent 可以自主选择其系统架构、算法和工具，生成或修改代码，并组织模型训练和实验。

SuperAgent 应根据当前任务、数据特征以及先前实验结果，决定下一步尝试什么，并通过进一步实验评估改动。方案选择、修改和执行结果均应记录在执行日志中。

## 4. 资源约束

SuperAgent 只能使用**在 2026 年 10 月 21 日当天或之前正式发布、且具有官方标准 API 定价的 Qwen 或 DeepSeek 模型**。可以通过任意 API 提供商访问这些模型，也可以本地部署。

最终报告中每个评估任务的**模型使用预算上限为人民币 20 元**。费用按模型在 2026 年 10 月 21 日的官方标准输入、输出 token 价格和实际 token 消耗计算，不考虑缓存折扣、平台促销或免费额度。本地部署模型也适用相同核算规则。

每组必须准确记录所有 Agent 的模型调用、输入和输出 token 用量及计算费用，并提交相应执行日志。**课程会抽查这些记录。** 不如实报告模型用量将导致扣分。

## 5. 评估与评分

最终成绩依据已提交 SuperAgent、公开任务和未见任务上的实验结果、源码与执行日志、项目报告以及最终展示评定。

| 项目 | 权重 | 评价内容 |
|---|---:|---|
| 性能：公开任务 | 20% | 公开任务完成情况与最终结果，包括未完成任务中有效的部分结果。 |
| 性能：未见任务 | 10% | 未见任务完成情况与最终结果，包括未完成任务中有效的部分结果。 |
| 通用 SuperAgent 设计与自主开发 | 30% | 通用性、系统设计、自主实验规划以及反馈驱动的改进。 |
| 执行、可复现性与报告 | 10% | 端到端成功运行、遵守资源约束、可复现性及报告质量。 |
| 最终展示 | 30% | 系统设计和实验结果的展示，以及组员对所提交系统与实验的理解。 |
| **总计** | **100%** | |

各组必须按每个任务公布的评估数据划分、指标和要求报告结果。SuperAgent 可以设计自己的内部验证流程，但**指定测试集只能用于最终评估，不得用于训练、超参数调优或方案选择**。

## 6. 提交要求与时间安排

每组必须提交：

1. **完整 SuperAgent 源码和统一执行入口**。
2. **`requirements.txt` 和 `README.md`**，说明依赖、环境配置和执行方法。
3. **为每个公开任务生成的最终分类模型或可运行预测方案，以及相应结果文件**。最终方案必须包含预测所需的预处理步骤和代码。
4. **`report.pdf`**，说明系统设计、主要实验、结果与局限。
5. **执行日志与实验记录**，包括候选方案、实验结果、关键决策和资源用量。
6. **AI 工具使用声明**。

所有报告结果必须由**同一个最终提交版本**的 SuperAgent 生成，并与提交的方案及执行日志一致。对于未完成的任务，各组应说明已取得的结果、执行失败的位置和原因。课程可能检查代码并复现部分结果。

最终项目时间安排如下：

| 阶段 | 安排 |
|---|---|
| **最终提交** | 根据各班课表，在**最后一周第一节课前一晚的 23:59** 之前，提交 SuperAgent 源码、报告和公开任务结果。随后冻结已提交的 SuperAgent 版本。 |
| **最终展示** | 最后一周按各班课表进行小组展示。 |
| **未见任务评估** | 两个班级（L01、L02）均完成展示后，课程发布一个此前未发布的分类任务。各组有 **24 小时**运行已提交 SuperAgent，并提交预测与执行日志。无需额外报告。 |

未见任务必须由最终提交时冻结的 SuperAgent 版本完成。运行期间不允许人工干预，并适用相同资源约束。

## 7. AI 政策

可以使用 AI 工具辅助项目开发，包括系统设计、编码、调试和测试。

所有组员均有责任理解并解释所提交 SuperAgent、关键设计选择和实验结果，并对提交的工作负责。
