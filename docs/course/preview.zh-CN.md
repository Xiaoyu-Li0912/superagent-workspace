# AIAA3102 期末项目：通用算法 SuperAgent（预告）

> 中文对照译文，供小组阅读，非官方中文版。翻译日期：2026-11-15。对应[英文 Preview](AIAA3102_Final_Project_Preview.md)。这是旧预告，不是当前最终要求；实际执行以[正式要求](assignment.zh-CN.md)及老师澄清为准。下文保留预告当时的表述，不将后来的预算、评分拆分或时间安排补写为预告内容。

**这是期末项目预告，完整作业要求将在一周内发布。**

## 1. 项目概览

本期末项目要求每组设计并实现一个**通用算法 SuperAgent（General Algorithm SuperAgent）**。

给定一个此前未见的任务、相应数据以及指定目标（本项目中为分类），Agent 应自主完成整个算法开发过程，包括分析任务与数据、设计方案、运行实验、根据实验结果改进方法，并最终生成一个可运行的分类模型。

最终报告中的结果必须来自 SuperAgent 完整、自主的运行。在这些运行期间，学生不得手动修改代码、决定下一步尝试什么，或选择最终模型。

课程将提供 API key 和使用额度，供本项目调用香港科技大学（广州）API 平台上的现有大语言模型，但不意味着只能使用该平台。更多细节将在**完整作业要求**中发布。

## 2. 任务

各组先有一段时间开发 SuperAgent。初期开发结束后，课程将发布若干分类任务，用于进一步测试和改进。

任务涉及表格、文本或图像数据上的二分类或多分类。各任务的数据格式、评估数据划分和指标将随任务公布。

所有任务必须由同一个 SuperAgent 处理。Agent 可以根据任务、数据和实验结果选择合适方法，但不得利用任务名称、数据集名称或其他任务身份信息，调用人工预先准备的任务专用方案。

## 3. SuperAgent 设计

各组可以自由设计 SuperAgent 的实现。

执行过程中，Agent 可以自主选择其系统架构、算法和工具，生成或修改代码，并组织模型训练和实验。

SuperAgent 应根据当前任务、数据特征以及先前实验结果，决定下一步尝试什么，并通过进一步实验评估改动。方案选择、修改和执行结果均应记录在执行日志中。

## 4. 资源约束

具体资源约束，包括允许的模型/API 和使用预算，将在完整作业要求中公布。

最终报告中的结果必须由 SuperAgent 在这些限制内自主运行产生，并有相应执行与资源用量记录。

## 5. 评估与评分

最终成绩依据已提交 SuperAgent、公开任务上的实验结果、源码与执行日志、项目报告以及最终展示评定。

| 项目 | 权重 | 评价内容 |
|---|---:|---|
| 性能 | 30% | 任务完成情况和最终结果，包括未完成任务中有效的部分结果。 |
| 通用 SuperAgent 设计与自主开发 | 30% | 通用性、自主实验，以及利用实验反馈修订和改进方案的能力。 |
| 执行、可复现性与报告 | 10% | 自主运行、遵守资源约束、实验和结果的可复现性以及报告质量。 |
| 最终展示 | 30% | 系统设计和实验结果的展示，以及组员对所提交系统与实验的理解。 |
| **总计** | **100%** | |

各组必须按每个任务公布的评估数据划分、指标和要求报告结果。SuperAgent 可以设计自己的内部验证流程，但**指定测试集只能用于最终评估，不得用于训练、超参数调优或方案选择**。

## 6. 提交要求

每组必须提交：

1. **完整 SuperAgent 源码和统一执行入口**。
2. **`requirements.txt` 和 `README.md`**，说明依赖、环境配置和执行方法。
3. **为每个任务生成的最终分类模型或可运行预测方案，以及相应结果文件**。最终方案必须包含预测所需的预处理步骤和代码。
4. **`report.pdf`**，说明系统设计、主要实验、结果与局限。
5. **执行日志与实验记录**，包括候选方案、实验结果、关键决策和资源用量。
6. **AI 工具使用声明**。

所有报告结果必须由同一个最终提交版本的 SuperAgent 生成，并与提交的方案及执行日志一致。对于未完成的任务，各组应说明已取得的结果、执行失败的位置和原因。课程可能检查代码并复现部分结果。

## 7. AI 政策

可以使用 AI 工具辅助项目开发，包括系统设计、编码、调试和测试。

所有组员均有责任理解并解释所提交 SuperAgent、关键设计选择和实验结果，并对提交的工作负责。
