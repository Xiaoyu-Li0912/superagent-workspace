## 算法边界与本次修正

- 已移除外层 monkey patch 和隐藏算法开关覆盖。读取上游 `config/config.yaml` 的原始算法配置：3 个初始草稿、3 路并行、分阶段生成、diff、全局记忆、停滞检测、evolution/fusion/aggregation、泄漏检查均保留原默认值。上游节点选择、回传、停滞条件与触发阈值未改。
- 恢复真实任务描述清理、指标方向判断、分阶段 Agent + 合并 Agent、LLM 代码审查/结果分析/方法摘要、记忆保存和检索路径；不是以外层固定脚本替代这些步骤。两阶段调度从上游 `run.py` 抽取为 `engine/scheduler.py`，保留先顺序生成草稿、再并行执行和续搜、按 journal 节点计步、普通异常续搜及默认 10 秒错峰。
- 冷启动知识库仍由上游加载；课程使用通用任务标识，不把优惠券等名字映射到人工预制方案。库中没有匹配项时按原实现返回无指导，不虚构已有知识。
- **必要差异**：课程要求 train/predict 分离与可信 accuracy；上游增加显式可选 I/O 接口，把 Kaggle 路径/环境提示改为真实课程接口，分阶段分工与 SEARCH/REPLACE 协议不变。上游仍作 LLM 结果分析与有效性判断，但指标只能来自监督器；外层冻结 `search.best_node`，不自行按原始分数重新选优。
- API 使用学校平台和统一账本；当前配置最大输出 32768 token、网络操作超时 1200 秒，结构化结果通过提示与 schema 校验而非原生工具调用返回，这些仍是与原提供方的差异，并非严格论文复现。采样/推理参数由上游 `llm/model_profiles.py` 提供，外层不再写死关闭 thinking；stop token 与结构化输出请求保留。临时网络错误会按配置进行最多 2 次有界重试，每次重试创建独立账本记录；不能确认 usage 的请求保留完整预留，不会被记成 0 元。
- CPU/沙箱/训练与预测各 600 秒、4GB 地址空间、100 步/28800 秒/400 调用/20 元均是本机实验约束，不是论文默认预算。累计未决未知用量达到 3 笔后停止新派发；鉴权、模型不合规、非法 usage 和预算超额等非临时错误立即停止。启用记忆但依赖/模型加载失败时，在首次付费调用前报错，**不静默关掉记忆继续跑**。

**以后改哪里：** 搜索、生成、记忆、触发策略及对应超参数改 `third_party/MLEvolve/`；预算/时间/调用数/执行资源改 `configs/runtime.yaml`；只有 API、数据协议、沙箱、计费及交付接口变化才改 `src/superagent/`。算法优化通常只需改 third_party，但新增库/资源/接口能力仍需配套基础设施，不能承诺所有改动永远只涉及一个文件夹。

## 长时间运行与网络恢复

| 配置项 | 当前值 | 含义 |
|---|---:|---|
| `steps` / `time_limit_seconds` | 100 / 28800 | 最多 100 个上游 journal 步数、8 小时搜索窗口，不等于 100 个成功模型 |
| `max_calls` / `budget_rmb` | 400 / 20 | 所有 Agent 和网络重试共享的派发次数、结算加预留上限，先到者限制运行 |
| `max_output_tokens` / `request_timeout_seconds` | 32768 / 1200 | 输出总 token 上限（包括提供方计入的推理 token）及底层网络操作超时 |
| `candidate_timeout_seconds` | 600 | 每次训练/预测各 600 秒；独立预测沿用该 run 的资源快照 |
| `network_retry_attempts` | 2 | 同一逻辑请求最多额外重试 2 次，每次都单独预留、记账，可能重复收费 |
| `network_retry_backoff_seconds` | 30 | 两次重试分别退避 30、60 秒，与冷却等待重叠，不简单相加 |
| `network_cooldown_seconds` | 120 | 临时故障后暂停新派发；冷却后只放一个探测请求，成功后放开其他请求 |
| `max_unknown_calls` | 3 | 累计未决 unknown 达到 3 笔后拒绝新请求，不是连续失败次数；成功不会清零旧预留 |

超时、连接中断、HTTP 408/425/429/5xx 等可尝试有界恢复；鉴权错误、证书验证失败、非法 usage、返回模型不合规等不重试。单个逻辑请求重试耗尽且仍有恢复额度时，抛普通临时异常交由上游按原异常路径处理；预算、调用数、deadline 或未知阈值命中时停止所有新派发。已在途请求会排空并记账，因此未知最终笔数可能超过阈值，但预算预留仍在派发前原子检查。按当前价格与上下文上界，单笔最大预留约 1.179648 元；预留不是确认扣款。

每次调度检查点保存 `checkpoint.json`、候选汇总及上游 journal。受控提前结束时，只要上游已经选出经可信执行验证的最佳节点，就冻结该节点并核验哈希；**不是保证任何失败都能产出模型**：初始化失败、始终没有有效候选、磁盘故障或强杀仍可能失败。检查点便于追溯，当前 CLI 不支持进程崩溃后的自动续跑，也不在外层跳过上游审查或重新选优。新策略尚未经过真实付费实验验证，不承诺运行满 8 小时或必得更高分。

当前实现及测试不等于所有模态已经通过真实任务评测；图像接口可接入，但尚未准备视觉预训练权重。当前状态统一维护在仓库根 README，关键工作历史在 journal.md，原始证据在 runs；不能把单元测试作为模型效果证据。
